# 搭建指南（技术初稿）

前提：OH2P、固件 1.62.2、已有可用 SSH。以下设备操作本轮未执行。
历史实机 SSH 来自小米同版 OTA 解包后按 stevenjoezhang/xiaoai-agent 的固件容器/Dropbear 思路制作的最小补丁，只改公钥认证与启动钩子，并非直接应用 open-xiaoai 的整套补丁。
出处：[xiaoai-agent OH2P 1.62.2 记录](https://github.com/stevenjoezhang/xiaoai-agent/blob/main/deploy/OH2P_1.62.2_BUILD_NOTES.md)；上游 xiaoai-plus 引用的另一条路线是 [open-xiaoai 教程](https://github.com/idootop/open-xiaoai/blob/main/docs/flash.md)。本仓库不含固件、刷机工具或补丁镜像；这里不提供未验证的刷机命令。

## 从源码构建（在仓库根目录逐条执行）
需要 Docker（amd64 仿真可用）、Git、curl、tar、Python 3。模型及 CA 不入仓库：官方 KWS 下载来源明确，权重独立许可未确认，请自行核实后使用。以下采用官方 zh-en 3M chunk-8 int8 权重；不下载其测试音频。

```sh
make -C xiaoai-plus/toolchain build-sherpa-static
make -C xiaoai-plus/toolchain compile
curl -fL https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20.tar.bz2 -o /tmp/xiaoai-kws.tar.bz2
tar -xjf /tmp/xiaoai-kws.tar.bz2 -C /tmp sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/encoder-epoch-13-avg-2-chunk-8-left-64.int8.onnx sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/decoder-epoch-13-avg-2-chunk-8-left-64.onnx sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/joiner-epoch-13-avg-2-chunk-8-left-64.int8.onnx sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/tokens.txt
cp /tmp/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/encoder-epoch-13-avg-2-chunk-8-left-64.int8.onnx xiaoai-plus/assets/encoder.onnx
cp /tmp/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/decoder-epoch-13-avg-2-chunk-8-left-64.onnx xiaoai-plus/assets/decoder.onnx
cp /tmp/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/joiner-epoch-13-avg-2-chunk-8-left-64.int8.onnx xiaoai-plus/assets/joiner.onnx
cp /tmp/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20/tokens.txt xiaoai-plus/assets/tokens.txt
curl -fL https://curl.se/ca/cacert.pem -o xiaoai-plus/assets/ca-certificates.crt
bash xiaoai-plus/toolchain/package-release.sh
docker build --platform linux/amd64 -t xiaoai-host-tests:public -f server/deploy/Dockerfile.host-tests server/deploy
docker run --rm --network none --platform linux/amd64 -v "$PWD/xiaoai-plus:/workspace" -w /workspace xiaoai-host-tests:public bash toolchain/offline-tests.sh
python3 -m venv .venv
.venv/bin/pip install -r server/requirements-dev.txt
.venv/bin/python -m pytest -q server/tests
```

安装包：`xiaoai-plus/dist/release/oh2p.tar.gz`。ARM ELF 应为静态链接；sherpa 补丁将 intra/inter_op.allow_spinning 均设为 0。离线测试不会连接付费云。

## 配置与安装
以下概括最近真实装机用过的 `/data/xiaoai-plus` 路径与启动方式；换成通用主机参数后的整段命令未验证。先备份已有目录，保留自己的配置与回退程序。不要覆盖原生小爱文件。

本机复制 `config.ini.example` 为私有 `config.ini`（权限 0600），填写 `[realtime] api_key`（火山语音 Key），`[memory] child_names = Amy, Ben`（与档案昵称一致）。`identity_question` 留空自动生成。可不启用记忆；启用时填写 HTTPS server_url、device_id、device_secret_file，秘密文件权限 0600。参考示例里的字段。

```sh
export SPEAKER_HOST=your-speaker-host
export SPEAKER_KEY=your-private-ssh-key
scp -i "$SPEAKER_KEY" xiaoai-plus/dist/release/oh2p.tar.gz root@"$SPEAKER_HOST":/data/xiaoai-package.tar.gz
ssh -i "$SPEAKER_KEY" root@"$SPEAKER_HOST" 'tar -xzf /data/xiaoai-package.tar.gz -C /data; mkdir -p /data/xiaoai-plus; cp -a /data/oh2p/. /data/xiaoai-plus/; chmod 755 /data/xiaoai-plus/boot.sh'
scp -i "$SPEAKER_KEY" config.ini root@"$SPEAKER_HOST":/data/xiaoai-plus/config.ini
ssh -i "$SPEAKER_KEY" root@"$SPEAKER_HOST" 'chmod 600 /data/xiaoai-plus/config.ini; /data/xiaoai-plus/boot.sh'
```

历史最小固件补丁的 `/etc/rc.local` 已有钩子：仅在 `/data/xiaoai-plus` 与可执行 boot.sh 都不是符号链接时后台运行 boot.sh。若你的 SSH 固件没有这个钩子，新增自启动步骤未验证，请按你的固件文档配置，不照搬修改 `/etc`。安装后需真实检查唤醒、声音、原生小爱/米家与断电自启；本轮未验证。

## 可选后台与家长页
以下通用部署命令未验证；软件测试已覆盖注册与档案接口。需要独立 Linux 主机、Python venv、systemd、Caddy、域名和 HTTPS。

`sudo bash server/deploy/install.sh --execute-on-authorized-server` 安装后，建立私有 `/etc/xiaoai-memory.env`，设置 `MEMORY_DB=/var/lib/xiaoai/memory.sqlite`、`MEMORY_DATA_KEY_FILE`、`MEMORY_ORIGIN=https://parent.example.org`；生成随机 32 字节 data key 的 hex 文件并设 0600、xiaoai 可读。部署源代码为 `/opt/xiaoai-memory/server`。

```sh
sudo bash server/deploy/admin.sh provision --household my-family --device my-speaker --child Amy --child Ben --secret-out /var/lib/xiaoai/device.secret
```

按提示输入家长密码；设备秘密只私下拷入音箱。配置 Caddyfile.example 的域名，反代本机 64100；检查配置后启用 `xiaoai-memory.service`。家长页补充档案。付费摘要模型 Key 通过 `sudo bash server/deploy/admin.sh set-ark-key` 输入；具体预算等配置见 server/ark_summary.py。`PARENT_URL` 是日报的家长页网址，留空不加链接。企业微信 webhook 放权限 0600 的文件，由 `WECOM_WEBHOOK_FILE` 指向，家庭由 `WECOM_HOUSEHOLD` 绑定。
