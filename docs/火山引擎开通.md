# 火山引擎开通

音箱当前默认 `protocol=o2`、`model=1.2.6.1`，使用 `wss://openspeech.bytedance.com/api/v3/realtime/dialogue` 的豆包端到端实时语音服务。不要误选只有文字聊天的方舟服务，也不要把新版3.0 duplex接口的协议配置直接套进来。作者此语音链路：已验证（作者一台音箱）；下面控制台页面路径：未在真机验证，以控制台为准。历史API_KEY_SETUP操作卡的闸门、固定地址和旧装机状态不适用于此通用安装。

1. 打开[火山引擎](https://www.volcengine.com/)，点右上角“注册/登录”，用自己的手机号完成注册。右上角头像进入“账号管理”→“实名认证”，按个人或企业实际身份提交认证（具体入口以控制台为准）。
2. 进入控制台，在产品搜索框搜“豆包语音”，进入语音控制台。先读[新版控制台快速入门](https://docs.volcengine.com/docs/doubao-voice/quick-start-new-console?lang=zh)。左侧“开通管理”，在语音大模型列表找到“端到端实时语音大模型”，核对支持O2版本后点击“开通”，阅读页面价格并确认。新版可能显示“API服务中心”，选择目标应用后开通，以控制台为准。查看[O/O2接口文档](https://docs.volcengine.com/docs/doubao-voice/end-to-endreal-time-speech-large-model-api-access-document?lang=en)的模型版本说明。
3. 在同一个语音控制台左侧“API Key管理”（也可能叫“API管理”）点“创建API Key”，选择刚开通服务的项目/应用，给Key取个自己能认出的名字并创建。单API Key认证由程序通过X-Api-Key发送；不要把方舟Key误填到语音配置。复制到自己Mac的 `.local/volc_key`，权限0600。Key不发聊天，不放命令参数或截图；09生成.local/config.ini并传到音箱，同样0600。页面位置参考[官方控制台说明](https://docs.volcengine.com/docs/doubao-voice/console-guidance?lang=en)，命名以控制台为准。
4. 右上角“费用”→“费用中心”→“账单管理/账单详情”，选择日期和语音产品看消费；语音控制台左侧“用量统计”选择项目、模型和日期看用量，购买过资源包则到“我的资源”看余额。菜单以控制台为准，参考[官方FAQ](https://docs.volcengine.com/docs/doubao-voice/console-usage-faq?lang=zh)。本项目不设每日费用或单次会话硬上限；30秒无人接话退出，实际收费以火山账单为准。

如果控制台只看到新版3.0，请先确认O2服务能否开通；拿不准就停止安装并向火山咨询，不盲改产品默认协议。服务开通和计费确认需要你本人完成，Agent不能凭Key格式判断服务可用。

## 可选记忆后台的方舟 Key（未在真机验证）

这是记忆摘要/身份识别用的独立Key，保存在你自己的记忆服务器，不进音箱语音配置。无后台就跳过，09默认memory.enabled=off。

打开控制台搜索“火山方舟”→进入“模型广场/开通管理”，选择server说明中配置的模型并开通；“API Key管理”→“创建API Key”→选择对应项目并创建，在服务器运行 `server/deploy/admin.sh set-ark-key`，按交互提示录入Key和模型ID（默认 doubao-seed-2-0-mini-260428），会做一次会计费的小请求校验。工具保存到 `/etc/xiaoai-memory/ark.env`（root与服务组可读0640，字段 ARK_API_KEY、ARK_MODEL）；不要在终端打印该文件或把Key放命令参数。具体见[server说明](../server/README.md)及server/ark_setup.py、server/ark_summary.py、server/ark_identity.py。页面可能显示“在线推理/创建推理接入点”，以控制台为准。方舟账单在费用中心单独查看。后台发给音箱的64位hex设备密钥与这两个云Key都不同；由后台provision生成，09通过 `--device-secret-file` 读取0600文件。
